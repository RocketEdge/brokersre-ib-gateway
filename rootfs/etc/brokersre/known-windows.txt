#   "IBC: detected (dialog|frame) entitled: <title>; event=Opened".
# A line that starts with "frame:" applies to frames only; any other line applies to dialogs
# and frames alike.
# A window whose title matches none of these lines (and no row of ibc-patterns.tsv) and that
# is still open after UNKNOWN_WINDOW_GRACE_S seconds raises the `unknown_window` event: nothing
# dealt with it, so it may block the login or the daily restart until a person looks at it.
#
# Sources: REAL = seen in this image's IBC output (IB Gateway 10.50.1g; the failed login of
# 2026-11-11 and the completed paper logins of 2026-11-15, tests/fixtures/ibc-real-*.log);
# IBC = a title IBC's source code looks for (IBC 3.24.2), so IBC handles the window itself.
#
# Deliberately NOT listed: "Warning". Every paper login opens a dialog with that title (this is
# not a brokerage account) and IBC accepts it at once, but the title says nothing about the
# content. The grace period covers the one IBC answers; a warning nobody answers is reported.
#
# REAL: the Gateway window (the login window, the main window and a confirmation dialog share
# the title)
